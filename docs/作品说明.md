# 货代 AI 客服中心 · 作品说明

一个面向中韩跨境物流客服场景的 AI 工作台。客户可以查询货物、询问清关和提交业务请求。员工在同一个工作台查看对话、工具结果和客户资料，确认需要人工处理的动作。项目覆盖报价、单据核对、双语知识库、模型评测及邮件自动化。

## 系统 Harness 架构

这里的 Harness 是把模型接入业务流程的执行层。它负责组装工单上下文、调用 DeepSeek、校验和执行工具、记录每一步结果，并将敏感变更交给员工确认。运费、差异判定和业务状态由应用程序及业务数据决定。

### 一条工单如何处理

```mermaid
sequenceDiagram
    actor C as 客户
    participant H as 工单 Harness
    participant M as DeepSeek API
    participant T as 工具与业务数据
    actor S as 员工

    C->>H: 询问提单的清关状态
    H->>M: 提供会话上下文和工具定义
    M->>H: 请求查询
    H->>T: 校验客户归属并读取状态
    T-->>H: 返回状态或知识库章节
    H->>M: 回填工具结果
    M-->>H: 生成答复
    H-->>C: 启用查询类自动回复时发送答复
    C->>H: 提交更正资料
    H->>M: 请求下一步处理
    M->>H: 请求创建更正草稿
    H->>T: 保存待确认的变更
    H-->>S: 显示草稿、工具记录和客户背景
    S->>H: 检查或编辑后确认
    H->>T: 提交变更并更新工单
    H-->>C: 发布已确认的回复
```

## 功能介绍

| 页面 | 可以做什么 |
| --- | --- |
| 客户聊天 `/chat` | 使用网页、微信、KakaoTalk、邮件或官网询价样式发起模拟会话。界面可切换中韩文，客服回复按客户消息语言生成。 |
| 员工工作台 `/workbench` | 浏览收件箱、会话、工具时间线和客户货物。查询仓库、物流和清关状态。检查、编辑、重写或确认回复草稿。 |
| 知识库 `/kb` | 检索中韩双语资料，定位到原文章节。关键词检索结合别名和 BM25，部署本地 E5 向量模型后启用混合检索。证据不足时说明查询限制。 |
| 报价 `/quotes` | 支持海运整柜、拼箱、轮渡和空运，依据费率、计费单位、船期和贸易条款计算。处理超权限折扣、正式 PDF 和理赔登记。 |
| 单据核对 `/documents` | 核对商业发票、装箱单和提单。可读取 PDF 文本或通过本地 OCR 处理照片，经操作员勾选也可使用 DeepSeek 提取。展示字段证据、差异、合规资料和处理草稿。 |
| 成绩单 `/evals` | 在同一案例集上比较 DeepSeek Flash、Flash 思考和 Pro 思考。展示分数、通过率、工具步数、用量、估算成本和逐例回放。 |
| 自动化流程 `/automation` | 用测试邮件触发 n8n 流程，按 Message-ID 去重。员工确认后产生模拟回信记录和客户跟进记录。 |

在项目根目录的 `.env` 配置 `DEEPSEEK_API_KEY` 后，可运行以下命令并打开 [员工工作台](http://127.0.0.1:8000/workbench)。

```powershell
.\scripts\start.ps1
```

运行邮件自动化时，在另一个终端执行 `.\scripts\start-n8n.ps1`。知识库混合检索与中韩文报价 PDF 使用本地模型和字体资源。安装步骤、样例和评测命令见 [项目 README](../README.md) 和 [演示脚本](demo.md)。

**技术栈**　React、TypeScript、FastAPI、SQLite、DeepSeek、ONNX Runtime、RapidOCR、ReportLab、n8n。
